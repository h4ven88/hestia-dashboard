## Build & Validation Pattern

All edits MUST follow this exact sequence:

```bash
# 1. View target lines in source
#    (always view before editing — line numbers shift between sessions)

# 2. Make the edit via str_replace in dashboard.html

# 3. Extract JS and validate syntax
sed -n '/<script>/,/<\/script>/p' dashboard.html | sed '1d;$d' > /tmp/check.js
node --check /tmp/check.js

# 4. Build (requires: npm install --save-dev clean-css terser)
node build.js

# 5. Validate minified output
node -e "
const fs = require('fs');
const html = fs.readFileSync('index.html','utf-8');
const m = html.match(/<script>([\s\S]*?)<\/script>/);
if (m) { fs.writeFileSync('/tmp/check_min.js', m[1]); console.log('Extracted ' + m[1].length + ' chars'); }
" && node --check /tmp/check_min.js
```

## Modules

### Athena (Voice Assistant)

Voice control module: wake word detection → speech capture → Cloud STT → command parsing → Claude AI → TTS response.

**Voice Pipeline (current — Sprint 6):**
```
Wake (OWW) → chime (650ms) → panel opens → OWW stops →
150ms mic release → MediaRecorder opens → user speaks →
silence detected (RMS < 10 for 3.5s) → auto-stop →
base64 encode → Google Cloud STT → transcript →
submit to Claude → TTS response → follow-up listening (5s) →
auto-close → OWW restarts
```

**Key Components:**
- **OpenWakeWord (OWW):** ONNX Runtime Web, custom-trained model, consecutive detection filter (2 scores > 0.6)
- **Cloud STT:** `MediaRecorder` (audio/webm;codecs=opus) → Google Cloud Speech-to-Text REST API. Universal — works on all browsers.
- **Silence Detection:** `AnalyserNode` RMS amplitude. Threshold: 10, timeout: 3.5s, initial delay: 750ms, hard cap: 15s.
- **Command Parser:** Natural language → device actions. Brevity target: 8–14 words for confirmations.
- **Google Cloud TTS:** Primary voice via `athenaGoogleSpeak()` using `AudioContext`/`GainNode` MP3 playback.
- **DNA Helix Animation:** Visual feedback — two strands, flowing dots, amber depth contrast, delta-time RAF loop.

**Google TTS Voice Map:**
```
en-US → en-US-Neural2-F
en-GB → en-GB-Neural2-C
es-ES → es-ES-Neural2-A
es-US → es-US-Neural2-A
```

**Key State Variables:**
```javascript
let _athenaRecorder     = null;   // MediaRecorder instance
let _athenaRecChunks    = [];     // audio data chunks
let _athenaSilenceTimer = null;   // silence detection rAF ID
let _athenaRecStream    = null;   // MediaStream for recording
let _athenaRecAnalyser  = null;   // AnalyserNode for silence detection
```

**Key Functions:**
- `athenaInit()` — entry point, starts OWW on desktop/tablet
- `athenaStartWakeDetection()` — loads OWW models, starts AudioWorklet
- `owwLoadModels()` / `owwStart()` / `owwStop()` — OWW lifecycle
- `athenaStartListening()` — opens MediaRecorder, starts silence detection
- `athenaStopListening()` — stops recorder, releases mic
- `athenaCloudSTT(blob, mimeType)` — sends audio to Google STT
- `athenaCallClaude(transcript)` — sends command to Claude API
- `athenaSpeak()` / `athenaGoogleSpeak()` — TTS output
- `_athenaStartSilenceDetection()` — RMS-based auto-stop
- `athenaClose()` — closes panel, restarts OWW

## Architecture Decisions (Locked In)

| Decision | Choice | Reason |
|----------|--------|--------|
| Voice transcription | Google Cloud STT | Universal — all browsers via getUserMedia + REST |
| Audio capture | MediaRecorder (webm/opus) | Standard API, supported everywhere except FireOS WebView |
| Silence detection | AnalyserNode RMS amplitude | Local, no cloud dependency, frame-accurate |
| Wake word engine | OpenWakeWord (ONNX RT Web) | Apache 2.0, browser-native, no server |
| TTS primary | Google Cloud Neural2 | High quality, consistent cross-browser |
| TTS fallback | Web Speech Synthesis | No key needed |
| AI | Anthropic Claude (claude-haiku-4-5-20251001) | Fast for home control |
| Hosting | Cloudflare Pages | Free, CDN, auto-deploy from GitHub |
