## Cloud Config Sync

Install once, discover always. New devices on the same network auto-configure without any user input.

### How it works
- When you configure Hestia on any device, the config is automatically synced to the cloud via Cloudflare Pages Functions + KV storage.
- Any new device that opens hestari.com on the same home network is automatically configured — no setup wizard, no pairing codes, no QR scans.
- Config is pushed on every boot and settings change, keeping the cloud entry current.

### End-to-end encryption (AES-256-GCM)
- All config data (hub IP, API keys, device mappings, preferences) is encrypted client-side before leaving the browser.
- The Cloudflare Worker only stores ciphertext — it cannot read your credentials.
- Encryption key is derived from your network's public IP using SHA-256 + AES-GCM. Devices on the same network derive the same key automatically.
- No plaintext secrets are ever stored in the cloud or visible in API responses.

### Architecture
- **Zero infrastructure cost** — runs entirely on Cloudflare's free tier (100K reads/day, 1K writes/day, 1 GB KV storage).
- **No accounts or registration** — discovery is passive, based on network identity.
- **30-day auto-expiration** — unused config entries are automatically cleaned up.
- **Home-ID pairing endpoint** — ready for cross-network fallback in a future release.

### Fallback chain
1. **Same network** — fully automatic IP-based discovery (zero input)
2. **Cross-network** — pairing code entry (coming in future release)
3. **Offline** — QR code sharing (coming in future release)

## Training Pipeline v2

Updated wake word training infrastructure for all 10 wake words.

- Rewrote `train_model.py` with built-in noise augmentation (SNR 3-20dB), volume shifting, time stretching, and pitch shifting.
- Deeper MLP classifier architecture (384-256-128-64) with StandardScaler normalization baked into ONNX export.
- 369 YouTube URLs curated across all 10 wake words (Athena, Artemis, Hestia, Apollo, Achilles, Andromeda, Hermes, Odin, Osiris, Anubis) — 35-39 sources each.
- Deprecated v1 training scripts archived.
