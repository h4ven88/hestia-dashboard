# v2.1.0 forum post

**v2.1.0 is up. Reminders now fire whether or not a dashboard is open.**

Until now a reminder only went off if a screen happened to be awake at that exact moment. Closed overnight, tablet asleep, tab shut, and the reminder just did not happen, with nothing to tell you. Your hub fires them now, so they arrive as a push notification instead.

**What changes for you**

- A reminder that fires while you are looking at a screen speaks and shows a banner, same as before. One that fires while nothing is open arrives as a push, and is waiting in Settings → Reminders when you next look.
- Each reminder shows **Not read / Read / Missed** with the time it was due. "Mark as read" clears it, and clears it on your other devices within seconds.
- Fifteen minutes unread marks it missed, and it stays missed. Nothing alerts twice for the same occurrence, so this cannot turn into a snooze that will not shut off.
- The board clears each morning. No history is kept: three days away says "missed", not a list of every day you were out. One-time reminders stay for a week since they do not come round again.

**You can edit a reminder now.** Previously a typo or a wrong time meant deleting it and starting over. There is an Edit control on every reminder that opens it prefilled.

**If you have a reminder that has never worked, this is probably why.** The form defaults to today's date and 08:00, which is in the past for most of the day, and saving that stored a reminder that quietly scheduled nothing. It now refuses to save a schedule that can never fire, and an existing one says **"Time has passed"** instead of leaving you guessing. Edit will fix it.

Also gone: "Today" and "Tomorrow" were worked out from elapsed time rather than the calendar, so a daily reminder due tomorrow at 09:44, read at 09:46 today, said **"Today at 9:44 AM"**. It said today and meant tomorrow, on most daily reminders, most of the day.

**Small one:** the dashboard version now shows in the footer, so you can see what a device is running without opening Diagnostics.

**Updating.** This one does change the companion app, so it is required. Paste `HestiaDashboard.groovy` over Apps Code → Save, open the Hestia app, click **⬇ Update Dashboard File**, then reload the dashboard.

**Push needs to be working**, since that is how a reminder reaches you when nothing is open. If Diagnostics shows Push Pipeline amber with `Permission: default`, use **Re-enable notifications** in Settings → Push Notifications.

**No companion app?** Reminders keep working the old way, only while a dashboard is open. The hub is what makes the rest possible.
