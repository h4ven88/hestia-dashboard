# Hestia v1.5.8 Release Notes

**Release Date:** 2026-08-16

---

## New Wake Words

Six new wake words join Athena, Artemis, and Hestia in **Settings → Athena → Wake Word**.

### Stable
| Word | Detection rate |
|------|-----------------|
| Odin | 51.3% |
| Achilles | 65.6% |
| Andromeda | 76.9% |

### Experimental
| Word | Detection rate |
|------|-----------------|
| Apollo | ~20% |
| Hermes | 14.2% |
| Anubis | 20.3% |

Experimental words are fully functional but detect less reliably than the stable set — the picker flags each one with an "(Experimental)" label so you know what to expect before switching.

All six were trained from scratch using the official local recipe (50k synthetic examples, 50k training steps, 3,500 false-activation penalty, 2 augmentation rounds, plus a small injection of real scraped audio clips) — the same pipeline used for Athena and the latest Hestia retrain.

---

## Removed

- **Osiris** — trained but benchmarked at just 2.1% detection, effectively non-functional as a wake word. Dropped rather than shipped broken; may return later with a larger training set.
