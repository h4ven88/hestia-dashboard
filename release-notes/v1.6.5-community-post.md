**Hestia v1.6.5 — Activity Log search, Push arm/disarm alerts, and voice reliability**

A batch of real feature work on top of the Diagnostics & Activity Log foundation from v1.6.4, plus a good amount of hardening from a full pre-native-wrapper security and reliability audit that never got its own post until now.

**What's new:**

- **Activity Log can now be searched, filtered, and paged back through** — Settings → Diagnostics used to cap it at the most recent 25 events with no way to see anything older. There's now a category filter, a text search box, and a "Load more" button for genuinely older history.
- **Push notifications for arming and disarming** — Announcements has always spoken every arm/disarm step out loud; Push never had an equivalent, only covering an actual intrusion trip. A new **Arm/Disarm Status** toggle in Settings → Push Notifications now covers "Arming Away," "Armed Home," "Disarmed," etc. — the same heads-up your Ring integration gives with its arming chime, now on your phone too.
- **Athena and Routines now confirm a command actually worked before saying so.** Athena used to say "Done" the instant she sent a command, regardless of whether the hub accepted it — since she's meant to be used hands-free, a rejected command could sound identical to a successful one. She now waits for real confirmation and says so plainly if something didn't go through. Routines had the same gap in their "N done, M failed" summary; fixed the same way.
- **Motion (and smoke/water/lock/contact) announcements no longer repeat themselves** — a sensor named "Motion Detector Loft" used to announce "Motion detected in the Motion Detector Loft." Now: "Motion detected in the Loft."

**Also included — hardening from a full security/reliability audit, all real bugs, none previously posted about:** stored-XSS escaping across device/room/camera/reminder/routine names, a boot hang on HTTPS + HTTP-only-hub setups, an Activity Log crash and a silent wrong-order bug, PIN lockouts that now survive a reload, push notification self-healing when a device silently falls out of registration, and Reminders now handling Daylight Saving Time transitions correctly. Full list in the [release notes](https://github.com/h4ven88/hestia-dashboard/releases/tag/v1.6.5).

**Requires updating `HestiaDashboard.groovy`** (or an update via Hubitat Package Manager) for the new arm/disarm push notifications and a couple of the Companion App reliability fixes to take effect.

Everything else — Cameras, Artemis's core arm/disarm flow, existing device controls — is unchanged in this release.
