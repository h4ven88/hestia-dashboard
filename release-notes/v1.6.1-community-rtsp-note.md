Quick update on this -- RTSP is supported now (v1.6.1).

Cameras can have an optional Live Stream URL alongside the snapshot URL. It uses Hubitat's built-in RTSP Camera Stream driver on C-8 Pro hubs, which transcodes your RTSP feed to MJPEG over HTTP -- Hestia just points at that. Add it in **Settings > Cameras** and you'll get a real live feed when you tap into that camera's expanded view.

A couple of things worth knowing:
* It's C-8 Pro only, since that's what Hubitat's driver requires.
* The grid/list views stay snapshot-only on purpose (keeps things light if you've got a few cameras), live playback is in the expanded per-camera view.
* Snapshot URL is still supported and still works fine on its own if you don't need live video, or your camera doesn't have RTSP.

Let me know if you run into any trouble getting the stream URL from the driver.
