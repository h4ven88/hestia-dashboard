# Hestia v1.6.2 Release Notes

**Release Date:** 2026-08-30

---

## Push Notifications

Hestia can now send real browser push notifications for door, window, lock, motion, smoke/CO, water/freeze, and alarm events, even when nobody has the dashboard open.

- **Settings > Push Notifications** — mirrors the Announcements section: an enable toggle, this device's delivery mode, a list of every registered device, category toggles (Doors, Windows, Locks, Motion, Alarming, Smoke/CO, Water/Freeze), and event-type toggles (Open/Unlock, Close/Lock).
- **Per-device delivery mode** — each device that registers for push picks one of three modes: Always, Armed only, or Don't push. Alarming, Smoke/CO, and Water/Freeze always reach every registered device regardless of this setting or arm state, the same way a physical smoke alarm doesn't care whether the burglar alarm is armed.
- **How it works** — the browser registers a Service Worker and subscribes via the Web Push standard (VAPID). Delivery runs through a small Cloudflare backend; Hestia never sees your notification content pass through any third party beyond the browser's own push service (e.g. Google's FCM for Chrome-based browsers).
- **The trigger lives in the Groovy app, not the browser.** Announcements work by having an open dashboard tab listen to the hub's live event stream. Push notifications need to work with no tab open at all, so detecting events and sending pushes now happens in the Hubitat companion app itself, polling Maker API every 25 seconds for door/window/lock/motion/smoke/water changes, and subscribing directly to HSM status and alerts for instant arm-state and intrusion-alarm delivery.

### You need to update the Groovy app for this to work

Unlike the dashboard file, the companion app's own source code has no auto-update mechanism on Hubitat unless it was installed through Hubitat Package Manager. If you installed it by pasting the code directly into Apps Code:

1. Open **Apps Code** on your hub, find **Hestia Dashboard**.
2. Replace the contents with the latest `HestiaDashboard.groovy` from the [GitHub repo](https://github.com/h4ven88/hestia-dashboard/blob/main/HestiaDashboard.groovy).
3. Save, then open the Hestia app instance and click **Done** once to re-initialize it.

If you installed via HPM, this update will show up as an available update the normal way.

Push notifications simply won't do anything until this step is done, everything else in Hestia keeps working exactly as before either way.
