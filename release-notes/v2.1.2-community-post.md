# v2.1.2 forum post

**v2.1.2 is up. If you updated to v2.1.0 or v2.1.1 and your reminders never fired, this is why.**

**Quickest fix, right now, with or without the update: open the Hestia app on your hub and click Done.**

The companion app registers its once-a-minute reminder job inside `initialize()`, which Hubitat runs only on install or update — and updating means opening the app and clicking **Done**. Pasting code into Apps Code and saving does not do it. Neither does "⬇ Update Dashboard File".

My v2.1.0 instructions told everyone to click Update Dashboard File and specifically not Done. That was wrong for that release, because that release was the one that added the job. So on any hub that followed them, the job was never scheduled. The hub reported the right version, answered every request correctly, held a perfectly good list of what was due, and never looked at it.

**The instructions were the trigger. The design was the bug.** The dashboard decided the hub was handling reminders based on the app's version number. A version number tells you what is installed, not what is running — so a hub with an unregistered job looked identical to a healthy one, and every open dashboard stood down and waited for a hub that was never going to act.

The hub now reports a heartbeat and has to prove it is actually running. No heartbeat, or a stale one, and your screens fire reminders themselves, the same as households with no companion app. It is judged against your hub's clock, not the device's, so a wall panel with a drifting clock cannot wrongly call a healthy hub dead.

The hub also repairs itself now: a reminder job that has not run in over eleven minutes gets re-registered, both when a dashboard checks in and on the app's own three-hour cycle, so a household that relies on push and keeps no screen open recovers too. If it genuinely cannot be repaired it stops after three tries and says so in the log instead of churning forever.

**Settings → Reminders now says which side is firing them** — "Fired by your hub" or "Fired by this device" — and what to do about it. That was invisible before, and it is the whole difference between a reminder that reaches you when everything is closed and one that does not.

**Updating.** Paste `HestiaDashboard.groovy` over Apps Code → Save → open the Hestia app → **Done** (required this time, it is what registers the job) → then **⬇ Update Dashboard File** → reload the dashboard. Footer should read v2.1.2, and Scheduled Jobs in the app's status page should list `reminderTick`.
