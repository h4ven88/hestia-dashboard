# Hestia v1.6.1 Release Notes

**Release Date:** 2026-08-19

---

## Cameras: refinements + live RTSP streaming

Based on real feedback after the v1.6.0 launch:

- **Home screen** — cameras now show as a full-width scrollable strip below the calendar instead of a dedicated grid card, so the home screen stays clean regardless of how many cameras you add.
- **Settings** — dropped the Room field (camera name is all that's needed), fixed the "+ Add Camera" button styling, and the list now scales cleanly to any number of cameras.
- **Dedicated view** — always renders a proper 4-tile grid, even with a single camera configured, with swipe paging for more.
- **New: live RTSP streaming.** Cameras can now have an optional Live Stream URL alongside the snapshot URL, using Hubitat's built-in RTSP Camera Stream driver (C-8 Pro hubs) transcoded to MJPEG. Tap into a camera's expanded view to see a real live feed instead of a still image. Grid/list views stay snapshot-only to avoid opening multiple live connections at once; a stream-only camera (no snapshot URL) shows a placeholder tile with a tap-to-view-live prompt.

## Cross-device config sync

Config (rooms, reminders, routines, dismissed devices, etc.) was previously only pulled from the hub once at boot, so a tab left open for a while could silently drift out of sync with changes made on another device. Hestia now periodically checks whether the hub's config is newer and shows a dismissible banner, or auto-refreshes on its own once the screen has been idle for 30 seconds and nothing on screen would be interrupted (no open Settings, PIN entry, Athena session, or live camera view).

## Bug fixes

- Garage door relays reporting both Switch and ContactSensor capabilities (e.g. Zooz Zen17) could get misclassified and auto-added to Artemis as a plain contact sensor instead of being recognized as a garage door.
- `packageManifest.json` hadn't been updated since v1.5.3, which meant Hubitat Package Manager wasn't surfacing newer releases as available updates.
