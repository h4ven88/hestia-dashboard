# Hestia v1.6.1 Release Notes

**Release Date:** 2026-08-23

---

## Cameras: refinements + live RTSP streaming

Based on real feedback after the v1.6.0 launch:

- **Home screen** — cameras now show as a full-width scrollable strip, sized and spaced to match the rest of the home screen's cards no matter the window height, instead of a dedicated grid card.
- **Settings** — dropped the Room field (camera name is all that's needed), fixed the "+ Add Camera" button styling, and the list now scales cleanly to any number of cameras.
- **Dedicated view** — always renders a proper 4-tile grid, even with a single camera configured, with swipe paging for more.
- **New: live RTSP streaming.** Cameras can now have an optional Live Stream URL alongside the snapshot URL, using Hubitat's built-in RTSP Camera Stream driver (C-8 Pro hubs) transcoded to MJPEG. Tap into a camera's expanded view to see a real live feed instead of a still image. Grid/list views stay snapshot-only to avoid opening multiple live connections at once; a stream-only camera (no snapshot URL) shows a placeholder tile with a tap-to-view-live prompt.
- **Security page** — the same camera filmstrip now also appears at the bottom of the desktop Security view, so a security check and a camera glance don't require switching pages.
- **Default Room** — Cameras can now be set as the startup view in Settings > Panel Behavior, alongside Home, Lights, Fans, Blinds, Climate, and Security.
- **Grid overflow fix** — on wide monitors, tiles in the dedicated Cameras view could balloon well past a sane size and clip the page with no way to scroll to what didn't fit. Tiles now cap at a fixed max width and the grid scrolls properly when content doesn't fit the window.
- **Mobile live RTSP playback** — camera tiles in the Security tab's camera list are now tappable, opening a detail view with the same live playback the desktop view has.
- **Camera image reliability** — camera `<img>` requests no longer send a referrer header, since some local camera/hub setups behave inconsistently when a request arrives with a foreign `Referer` from a cross-origin page like hestari.com.
- **Live stream now polls instead of loading once** — Hubitat's own dashboards consume the hub2/videoStream endpoint via a polled Image tile (a "Refresh Interval" field, commonly ~1s) rather than a single persistent connection. The live view now re-requests the current frame every second while open, matching that reference behavior, instead of loading once and giving up on failure.

## Room-level lock badges

Locks can now be assigned to a room in Settings > Door Locks. The sidebar shows an "Unlocked" badge on that room when an assigned lock is unlocked, purely informational, actual lock control still lives in the existing Locks/Artemis flow.

## Navigation: Global tab

Mobile's bottom nav "Blinds" tab is now a "Global" tab that opens a menu to Lights, Fans, Blinds, and Climate, whichever have devices configured. Lights and Fans previously had no dedicated bottom-nav entry point at all.

## Cross-device config sync

Config (rooms, reminders, routines, dismissed devices, etc.) was previously only pulled from the hub once at boot, so a tab left open for a while could silently drift out of sync with changes made on another device. Hestia now periodically checks whether the hub's config is newer and shows a dismissible banner, or auto-refreshes on its own once the screen has been idle for 30 seconds and nothing on screen would be interrupted (no open Settings, PIN entry, Athena session, or live camera view).

## Bug fixes

- Garage door relays reporting both Switch and ContactSensor capabilities (e.g. Zooz Zen17) could get misclassified and auto-added to Artemis as a plain contact sensor instead of being recognized as a garage door.
- `packageManifest.json` hadn't been updated since v1.5.3, which meant Hubitat Package Manager wasn't surfacing newer releases as available updates.
- Toggling Artemis on/off could silently break camera navigation, since the routing table it rebuilds on toggle was dropping Cameras from the valid list.
