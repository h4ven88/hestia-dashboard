# v2.1.3 forum post

**v2.1.3 is up. If you've been trying to recover a device that lost its household key, this one's for you.**

@jbwrd3 followed my instructions from the other day and got a blank page. That was my fault and here's why: I said to take `appId` and `token` out of `hestia-token.json`, and that file actually holds four credentials, not two — `appId`/`token` for the Hestia companion app, and `makerApiAppId`/`makerApiToken` for Maker API. Grab the wrong pair and you get a blank page with nothing telling you which mistake you made.

**The recovery screen builds the link for you now.** Paste the whole of `hestia-token.json` into the first box, hit **Build my link**, open what it gives you, and paste that back in. It picks the right pair, works out your hub address from the file, and refuses a paste that only has the Maker API fields rather than handing you a link that cannot work.

It also tells you what a blank result means: if that page is empty or says `null`, your hub has no saved settings, and starting fresh is the right answer rather than hunting for a key that isn't there.

**Two fixes in Diagnostics as well.** Settings → Diagnostics was still telling people to "open Hestia on a device that is already working" — which is impossible for exactly the people reading it, since if a device still worked they wouldn't be. I corrected that wording on the recovery screen in 2.1.2 and missed this copy of it.

It was also hiding the most useful thing it knew. If your settings couldn't be read, it said only that, and nothing about whether your *saves* were being rejected too. Those are different problems with different fixes. That now shows up.

Worth knowing if you've tried starting fresh and it didn't stick: setting up over your own existing record is authorised by the Maker API token stored in it, so a **newly generated** token gets refused — it completes on that device and never reaches the others. Use the token you already had.

**Updating.** Reload hestari.com and you have it. For a hub-served dashboard, paste `HestiaDashboard.groovy` over Apps Code → Save → open the Hestia app → **⬇ Update Dashboard File**. **You don't need to click Done this time** — the app's code is unchanged here, its version just moves with the dashboard so the two don't look out of step.
