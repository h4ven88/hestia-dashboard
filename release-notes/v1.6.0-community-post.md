## Hestia v1.6.0 - Cameras

Hey everyone, v1.6.0 is live. Hard refresh (Ctrl+Shift+R) to pick it up.

---

### Cameras

New module, configured in **Settings > Cameras**.

* **Works with any camera or integration** -- add a name, room, and a snapshot URL (any URL that returns a still image when fetched). Hestia doesn't care what produced it, so it's not tied to one brand.
* **Manual reorder** -- up/down buttons in Settings control display order everywhere cameras appear.
* **Desktop/tablet** -- new sidebar item between Lights and Security, showing up to 4 snapshots at once with pagination for more, per-camera refresh, and a 30-second auto-refresh while the view is open.
* **Mobile** -- no new bottom tab. Cameras live inside the Security tab as a quick "N online" row, tapping through to a scrollable list of thumbnails.

### If you're on Ring

The official Ring integration doesn't expose snapshots. There's a working path through Hubitat's built-in Dashboard app tile endpoint that works even via the unofficial Ring integration, no go2rtc or extra bridges needed. Happy to help anyone stuck finding their URL.

### One gotcha to know about

If a camera shows "Offline" but the URL works fine pasted into a browser tab, it's almost certainly mixed content -- the dashboard is HTTPS, most local camera/hub URLs are HTTP. Switching to `https://` on your hub's local IP and accepting the certificate warning once (same fix as the existing "Hub connection is using HTTP" banner) usually clears it.
