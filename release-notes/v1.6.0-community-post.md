🎥 Hestia v1.6.0 — Cameras!

Hey everyone,

Bigger one this time — v1.6.0 adds a Cameras module to the dashboard.

**How to set it up:** Settings → Cameras → give it a name, room, and a snapshot URL (any URL that returns a still image when fetched — works regardless of brand or integration). Reorder with the up/down buttons.

**Where you'll see it:**
- Desktop/tablet: a new sidebar item, showing up to 4 camera snapshots at once with pagination for more
- Mobile: no new bottom tab — cameras live inside the Security tab as a quick "N online" row, tapping through to a scrollable list

**If you're on Ring:** the official Ring integration doesn't expose snapshots, but there's a working path through Hubitat's built-in Dashboard app tile endpoint even via the unofficial integration — no go2rtc or extra bridges needed. Happy to help anyone stuck finding their URL.

**One gotcha to know about upfront:** if a camera shows "Offline" but the URL works fine when you paste it into a browser tab, it's almost certainly a mixed-content issue (hestari.com is HTTPS, most local camera/hub URLs are HTTP). Switching to `https://` on your hub's local IP and accepting the certificate warning once — the same fix already recommended for the hub connection — usually clears it right up.

Let me know how it goes, especially if you're running something other than Ring — curious what other camera setups look like in the wild.
