# Hestia v1.5.6 Release Notes

**Release Date:** 2026-06-13

---

## International Weather Support (Open-Meteo)

The weather module has been completely rebuilt. The previous US-only stack (NWS API + ZIP code lookup) has been replaced with [Open-Meteo](https://open-meteo.com/) -- a free, international weather API that requires no API key.

### What changed
- **City search replaces ZIP code** -- Settings now has a "City or Location" field. Type a city name, pick from proximity-ranked results showing city, state/region, and country.
- **Works worldwide** -- weather data is available for any location, not just US ZIP codes.
- **Coordinates stored** -- latitude and longitude are saved in config, so weather loads instantly on subsequent boots.
- **Same visual layout** -- the home screen weather card looks identical; only the data source changed.

### Weather display improvements
- **Day/night forecasts restored** -- forecast now shows half-day periods (Tonight, Tomorrow, Tomorrow Night, etc.) instead of just daily summaries.
- **Precipitation probability** -- rain/snow chance is shown with a raindrop icon on forecast periods when above 20%.
- **Dark theme icon fix** -- weather SVG icons (clouds, fog) are now properly visible on all dark themes.
- **Friendlier descriptions** -- "Overcast" is now "Cloudy", "Mainly Clear" is now "Mostly Clear", "Snow Grains" is now "Flurries", "Rain Showers" is now "Showers", "Thunderstorm with Hail" is now "Severe Thunderstorm".

## Fan + Light Combo Device Support

Devices that control both a fan and a light (like Inovelli Blue switches wired to fan/light canopies) can now have both sides assigned independently through the device picker.

### How it works
- **Dedicated fan switches** (GE, Zooz, etc.) continue to work as plain fans. The `Switch` capability on a fan controller is recognized as the fan's own on/off, not a separate light.
- **Combo devices** (Inovelli, etc.) that control both a fan and a light on the same device can be assigned to both categories:
  - The fan side appears normally in the Fans device picker
  - The light side appears as "Device Name (Light)" in the Dimmers or Switches picker
- The light side type is determined by the device's capabilities: if it has `SwitchLevel`, it becomes a dimmer with brightness control; otherwise a basic switch.
- **No auto-splitting** -- dedicated fan controllers are never mistakenly split. Only users with true combo devices opt in by assigning both sides.

## Temperature Unit Toggle

Three display modes for temperature throughout the dashboard:

| Mode | Label | Behavior |
|------|-------|----------|
| Fahrenheit | F | Raw values from hub, displayed as F |
| Celsius (label only) | C | Raw values from hub, displayed with C label |
| Celsius (converted) | C | Values converted from F to C using standard formula |

Settings location: **Settings > Thermostats > Temperature Display Unit**

Applied to: home screen, climate card, room views, topbar ribbon, sidebar nav, and Athena voice context.

---

## Auto-Hide Empty Categories

Device categories with zero devices are now automatically hidden across the entire UI:

- **Home screen** -- Fans, Blinds, and Climate cards only appear when you have devices of that type
- **Sidebar nav** -- Fan, Blinds, and Climate links hidden when empty
- **Mobile bottom tabs** -- Blinds and Climate tabs hidden when empty
- **Topbar ribbon** -- Fan, shade, and thermostat stats hidden when empty

No configuration needed -- the UI adapts automatically based on your device inventory. Categories reappear if devices are added later.

## Bug Fixes

- **Theme contrast** -- updated `--t3` and `--t4` CSS variables across all 5 themes (dark, light, slate, warm, cream) to meet WCAG AA contrast ratios
- **Security as default room** -- Artemis now appears in the Default Room dropdown when the security module is enabled
- **Config sync** -- reverted to hub-is-truth model to prevent stale cloud/hub configs from overwriting local changes
