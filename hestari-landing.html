Why Hestia

What makes it different.

Other dashboards show you buttons. Hestia gives you a voice assistant, a security system, and a single-file architecture that just works.

01

Natural language voice control

Athena uses Claude AI to understand what you mean, not just what you say. Multi-device commands, thermostat modes, timers, follow-up conversations, and persistent memory across sessions.

02

Security system built in

Artemis integrates directly with Hubitat Safety Monitor. Arm, disarm, monitor sensors, and receive intrusion alerts — no separate security app needed.

03

Hands-free wake word

Say "Athena" from across the room. On-device wake word detection runs entirely in your browser — no cloud, no always-listening server.

04

Single file, zero dependencies

The entire dashboard is one HTML file served from your hub. No Docker, no database, no Node server. Update by replacing one file.

05

Private by default

Device control stays on your local network. Voice features use encrypted cloud APIs only when you speak. No telemetry, no accounts, no data collection.

06

Wall panel ready

Designed for always-on wall-mounted displays. Auto-boots, stays connected, and listens for wake words continuously. Like a smart speaker with a screen.

One Dashboard, Every Screen

Hestia adapts to the screen it is on. The same dashboard works on your phone in your pocket, a tablet on the nightstand, your desktop at work, or a wall-mounted panel by the front door. No separate apps, no syncing, no duplicate setup.

Setup Guide

Getting started, step by step.

The full walkthrough from install to first voice command. Most steps take under a minute.

1

Install via Hubitat Package Manager

▸

Open your Hubitat hub in a browser and navigate to Apps → Hubitat Package Manager.

Select Install, then search for "Hestia".

HPM will install the Hestia companion app on your hub. Once complete, you will see it listed under Apps.

2

Set up Maker API

▸

Hestia communicates with your devices through Maker API. If you do not already have it installed:

  • Go to Apps → Add Built-in App → Maker API
  • Select the devices you want Hestia to control
  • Enable "Allow Access via Local IP Address"

If Maker API is already installed, open it and make sure your devices are selected.

Take note of your App ID and Access Token from the Maker API page. You will need these when connecting the dashboard.

3

Configure CORS permissions

▸

If you plan to use the dashboard from hestari.com (rather than your hub's local address), you need to allow it to communicate with your hub.

Open the Hestia companion app on your hub (Apps → Hestia Dashboard). It handles CORS headers automatically for hestari.com.

If you also use Maker API directly, add the following to its "Allowed Hosts (for CORS)" field:

https://hestari.com, https://www.hestari.com

If you only plan to use the dashboard from your hub's local address, you can skip this step.

4

Open and connect the dashboard

▸

Open the dashboard at hestari.com or your hub's local address.

The onboarding wizard will appear on first launch. Enter your hub's IP address, Maker API App ID, and Access Token when prompted.

Hestia will connect to your hub and discover your devices automatically.

5

Set up rooms and devices

▸

Open Settings → Devices to organize your home.

  • Create rooms and assign devices to them using the dropdown next to each device
  • Drag and drop to reorder devices within a room
  • If Hestia detected a device type incorrectly, use the type dropdown to change it (for example, switching a dimmer that was detected as a switch)

Devices that are not assigned to a room will appear in an "Unassigned" group in settings but will not show on the main dashboard.

6

Configure climate controls

▸

If you have thermostats, go to Settings → Climate.

Set your location coordinates so Hestia can display current weather conditions alongside your thermostat controls. You can enter your city or allow the browser to detect your location.

If you do not have any thermostats, you can skip this step.

7

Set up Artemis security

▸

Artemis integrates with Hubitat Safety Monitor (HSM). If HSM is active on your hub, Artemis will detect it automatically.

  • Set a PIN code for arming and disarming
  • Configure which sensors are monitored in each mode (Home, Away, Disarmed)
  • Artemis will display real-time alerts for open doors, windows, motion events, and intrusions

If you do not use Hubitat Safety Monitor, the Artemis panel will show setup instructions for enabling it.

8

Enable Athena voice (optional)

▸

Athena requires two API keys to work. Both services offer free tiers that are more than enough for home use.

AI Provider (for understanding commands):

  • Claude AI by Anthropic (supported now): Create an API key at console.anthropic.com
  • ChatGPT by OpenAI and Gemini by Google: Coming soon as additional provider options

Google Cloud (for voice input and output):

  • Create a Google Cloud project and enable the Speech-to-Text API and Text-to-Speech API
  • Generate an API key restricted to these two APIs
  • Free tier includes 60 minutes of speech recognition and 1 million characters of text-to-speech per month

Enter both keys in Settings → Athena Voice. Once configured, tap the Athena button or say "Athena" to start a voice command. You can also customize your wake word, personality, and conversation behavior in the same settings panel.

About

Built by a Hubitat user.

Hestia started as a personal project by Haven. A single HTML file on a Hubitat hub, built to control a few lights and a thermostat. It grew into something bigger: a dashboard that handles every device in the house, a voice assistant that understands natural language, and a security panel that ties into Hubitat Safety Monitor.

The name comes from Greek mythology. Hestia is the goddess of the hearth and home. Athena, goddess of wisdom, powers the voice assistant. Artemis, the huntress and protector, guards the house. Three goddesses, three modules, one dashboard.

Hestia is free, open source (Apache 2.0), and built in public. Contributions, feedback, and feature ideas are always welcome.

Roadmap

What is coming next.

Hestia is actively developed. Here is what we just shipped and what is planned.

Just Shipped

Timers, memory, and conversation mode

Set timers by voice with live countdowns. Athena remembers your conversation across page refreshes and keeps listening for follow-ups without re-waking.

Full device control and personality

Thermostats, color bulbs, shades, and every device type now controllable by voice. Choose from four personality presets to match your style.

Selectable wake words

Choose between Athena, Artemis, and Hestia — each with a custom-trained detection model. Seven more mythology-inspired options coming soon.

Artemis security system

Hubitat Safety Monitor integration with arm/disarm modes, PIN protection, real-time sensor alerts, and intrusion detection.

Companion app for Hubitat

One-click install via HPM. Auto-downloads the dashboard, handles CORS, and keeps you on the latest version.

In Progress

Wake word accuracy improvements

Training all wake word models with diverse real-world audio to achieve single-attempt reliability across accents and environments.

More wake word models

Apollo, Achilles, Andromeda, Hermes, Odin, Osiris, and Anubis. Each requires individual training and validation.

Planned

Multi-provider AI support

Choose your preferred AI provider. ChatGPT by OpenAI and Gemini by Google will join Claude as options — use whichever you prefer or already have an API key for.

Reminders and routines

Persistent reminders that survive page refreshes and named routines — "run movie mode" to execute a sequence of commands with one phrase.

Calendar integration

Google Calendar events shown in the dashboard. Athena can announce upcoming events and answer questions about your schedule.

Native apps

Dedicated apps for Windows, macOS, Android, and iOS. Background wake word listening, seamless local connectivity, and push notifications.
